# 당구 솔버 2.2 (Billiard Solver)

로블록스 캐롬 당구(4구 · 4구 마무리 3쿠션 · 3구 3쿠션)를 **혼자 연습할 때** 쓰는 Windows용 샷 계산 오버레이입니다.
F2를 누르면 게임 화면을 읽어서 득점 경로, 조준 각도, 추천 힘을 게임 화면 위에 그려 줍니다. 기본은 **무스핀(정중앙)**입니다.

> 화면 캡처만 읽습니다. 게임 파일이나 메모리는 건드리지 않고, 대신 쳐 주지도 않습니다.
> 다른 사람과 하는 대전에서는 쓰지 마세요. 상대에게 불공정하고 게임 규칙에 어긋날 수 있습니다.
> 이 프로젝트는 Roblox Corporation 및 게임 제작자와 관계가 없습니다.

## 기능

- **득점 경로 계산**: 수구 경로를 쿠션 반사·공 충돌까지 따라가서 득점되는 각도·힘·당점을 찾습니다.
- **추천 순서** (2.2): ① 무스핀으로 공 먼저 맞히는 샷 → ② 그게 없을 때만 스핀 샷 → ③ 쿠션 먼저 샷은 최후 수단.
  스핀이 필요하면 패널과 수구 옆에 게임의 당점 공처럼 찍을 자리를 그려 줍니다 (예: `12시 1팁 (밀어치기)`, 세기는 추정).
- **실전 득점률로 순위** (2.0): 후보마다 조준·힘·당점을 조금씩 틀리게, 물리값도 조금씩 다르게 32번 쳐 보고
  실제로 들어간 비율을 "안정성 %"로 보여 줍니다. 비슷하면 **짧은 경로·적은 쿠션**을 우대합니다.
- **내 조준 시뮬레이션 (F5)**: 게임 조준선과 안내선을 읽어서 *지금 조준대로 치면* 수구가 어디로 가는지 끝까지 그려 줍니다.
  첫 충돌 뒤 방향은 게임 안내선을 그대로 따르고, 경로는 거리 제한 없이 이어서 보여 줍니다.
  힘은 경로 위 예상 정지 위치(40/60/80/100%)로 표시하고, 득점이 안 되면 이유와 조금 돌리면 득점되는 각도를 알려 줍니다.
  **실시간** 버튼을 켜면 조준을 움직이는 대로 따라갑니다.
- **후보 3개 + 안정성 %**: 숫자가 높을수록 실수해도 들어가는 샷입니다.
- **목표 링 조준 도우미** (2.1): F2 추천 뒤 F5(또는 실시간)를 켜면 금색 목표 원이 뜹니다. 게임 링을 거기에 겹치면 "✓ 일치".
- **게임 안내선과 같은 방향**: 공 맞은 뒤·쿠션 반사 방향을 게임이 그리는 흰 안내선 기준으로 계산합니다.
- **모드 3개**: 4구 / 4구 마무리(3쿠션) / 3구(3쿠션). 고른 모드 그대로만 계산합니다 (자동 전환 없음).
- **공 인식**: 태극 무늬 같은 마크가 있는 공, 조준선·고스트볼 링이 닿은 공, 붙어 있는 공도 인식합니다.
- **조작 패널**: 버튼으로 전부 조작할 수 있고, 눌러도 게임 창 포커스를 뺏지 않습니다. 화면 배율(125~200%)에 맞춰 커집니다.
- **기록 없음**: 설정 파일(`settings.json`, 모드·내 공 색) 하나만 저장합니다. 로그나 이미지는 남기지 않습니다.

## 설치

필요한 것: Windows 10 (2004 이상) 또는 11, [Python 3.9 이상](https://www.python.org/downloads/)
(설치할 때 **Add python.exe to PATH** 체크)

1. 이 저장소를 내려받습니다 (Code → Download ZIP 후 압축 풀기, 또는 `git clone`).
2. `install.bat`을 더블클릭합니다. 가상환경(`.venv`)을 만들고 패키지를 설치한 뒤 바탕화면에 **당구 솔버** 바로가기를 만듭니다.
3. 바로가기(또는 `run.bat`)로 실행합니다.

## 사용법

1. 게임에서 내 차례가 되면 **F2** (또는 패널의 큰 버튼).
2. 화면에 1순위 경로(초록), 2·3순위(주황·하늘)가 그려집니다. 실선은 득점 순간까지, 점선은 그 뒤 경로입니다.
   원은 첫 번째 공에 맞는 순간 수구가 있을 자리(고스트볼)입니다.
3. 패널의 **추천 당점** 그림(빨간 점)대로 게임에서 당점을 찍고, 게임 조준선을 실선에 맞추고, 수구 옆에 표시된 힘으로 칩니다.
   당점을 쓰기 싫으면 패널의 **스핀: 끔**을 누르면 정중앙 샷만 추천합니다.

**내 조준 시뮬레이션** (4구 마무리처럼 F2로 경로가 잘 안 나올 때 직접 길을 찾아보기)

1. 게임에서 원하는 방향으로 조준합니다 (흰 조준선과 고스트볼 링이 보이는 상태).
2. **F5** (또는 패널의 보라색 버튼). 지금 조준대로 친 경로가 분홍색으로 그려집니다 (득점 경로면 초록색).
   - 공·쿠션에 맞은 뒤 방향은 게임이 링에서 그려 주는 안내선을 그대로 따릅니다.
   - 경로는 거리 제한 없이 쿠션·공 8번까지 이어집니다. 흰 점은 힘 40/60/80/100%일 때 예상 정지 위치입니다.
3. 화면 위 글씨로 결과를 봅니다.
   - `이 방향: 빨1 → 쿠션3 → 빨2 → 득점 경로!`  /  `필요한 힘(예상): 65% 이상`
   - `이 방향: 빨1 → 쿠션2 → 빨2 → 두 번째 공 전에 쿠션 2개 (3개 필요, 1개 부족)`
   - `가장 가까운 득점: 조준을 시계 방향으로 0.30° 돌리기 (초록 점선)`
   - 힘은 예상치입니다. 경로 모양(방향)은 힘과 상관없이 정확하고, 힘은 어디서 멈추는지만 바꿉니다.
4. 패널의 **실시간** 버튼을 켜면 F5를 계속 누르지 않아도 조준을 움직이는 대로 경로가 따라옵니다 (초당 2~3번).

| 키 | 동작 |
|---|---|
| F2 | 분석 (다시 누르면 다시 분석) |
| F3 | 선 지우기 |
| F4 | 내 공 색 (흰공 / 노란공) |
| F5 | 내 조준 시뮬레이션 (지금 조준대로 치면 어떻게 되나) |
| F6 | 모드 바꾸기: 4구 → 4구 마무리(3쿠션) → 3구(3쿠션) |
| F7 | 다음 후보 강조 |
| F8 | 후보 전부 / 하나만 |
| Ctrl+Shift+Q | 종료 |

패널의 "인식: 흰 1 · 노랑 1 · 빨강 2" 줄로 공을 다 찾았는지 바로 확인할 수 있습니다. 모자라면 주황색으로 표시됩니다.

## 동작 원리

1. **화면 인식** (`detector.py`): 파란 천 색으로 테이블과 쿠션 안쪽 경계를 찾고, 천이 아닌 덩어리 중 공 모양인 것을 색으로 분류합니다.
   마크 구멍을 메우고, 공의 바깥 테두리에 원을 맞춰 중심을 정합니다 (튀어나온 조준선·들어간 마크 부분은 제외).
2. **경로 계산** (`physics.py`): 직선 + 쿠션 반사(법선·접선 반발) + 공 충돌 뒤 수구 방향으로 수구 경로를 따라갑니다.
3. **샷 탐색** (`solver.py`): 정중앙은 각도 0.25° × 힘 30~100%, 당점 24가지(상하좌우 ±1·2팁 조합)는 0.5° × 힘 40~100%로
   훑고, 득점되는 각도는 0.05°까지 좁힙니다. 후보마다 조준(σ0.12°)·힘(σ7%)·당점(σ1/4팁) 실수와 물리값 오차를
   한꺼번에 넣어 32번 쳐 본 득점률로 순위를 정합니다. 1~2초 걸립니다.
4. **내 조준 읽기** (`aimpreview.py`): 수구에서 나가는 흰 조준선에 직선을 맞추고, 끝의 고스트볼 링에 원을 맞춰
   수구 중심→링 중심 방향으로 조준 각도를 잽니다 (테스트 기준 오차 0.03° 이내). 링에서 나가는 안내선으로
   맞은 뒤 수구 방향(또는 쿠션 반사각)을 읽어 그 값으로 경로를 이어 그립니다.
5. **오버레이** (`app.py`, `panel.py`): 클릭이 통과하는 투명 창에 그리고, 그 창은 화면 캡처에서 빠지게 해서 다음 분석에 섞이지 않게 합니다.

방향을 정하는 물리값(공 맞은 뒤 접선 방향, 쿠션 반사 비율 0.86)은 게임이 그리는 안내선에 맞춘 값입니다.
당점 효과의 세기와 힘-속도 곡선은 아직 "미확정"입니다 ([docs/CALIBRATION.md](docs/CALIBRATION.md)).

## 한계

- 당점 효과는 충돌 순간의 방향 변화로만 넣었습니다 (실제처럼 휘는 곡선은 그리지 않음). 효과 세기는 추정값입니다.
- F5 내 조준 시뮬레이션은 F2 추천 샷이 있으면 그 당점으로, 없으면 정중앙으로 계산합니다.
- 힘(거리)은 방향보다 덜 정확합니다 (예상치).
- 3쿠션 경로는 힘과 조준 오차에 민감합니다. 안정성 %가 높은 후보를 고르세요.
- 게임 테마(천 색 등)가 바뀌면 `detector.py` 위쪽 색 범위를 고쳐야 할 수 있습니다.
- 녹화 프로그램(OBS 등)에는 오버레이 선이 안 찍힐 수 있습니다 (캡처 제외 설정 때문).

조준선 각도 읽기와 "조금 돌리면 득점" 제안, 당점 효과 방향(오른쪽 당점 → 쿠션에서 오른쪽)과 스핀 샷이 실제로 득점하는지를 확인합니다.

## English summary

A Windows overlay for **solo practice** in Roblox carom billiards (4-ball, 4-ball 3-cushion finish, 3-ball 3-cushion).
Press F5 to read your current in-game aim line and see where that exact shot goes, which powers score, why it misses, and the nearest scoring correction (live-follow mode available).
Press F2: it reads a screenshot, detects the table and balls (including balls with a blue taegeuk mark), ray-traces the cue ball through cushions and ball contacts, and draws the top 3 scoring shots with angle, power, recommended spin (tip position, drawn like the in-game cue-ball picker) and a success rate estimated by replaying each shot 32 times with random aim/power/spin/physics errors. Shorter, simpler shots win ties.
It only reads the screen, never touches game files or memory, and does not shoot for you. Please don't use it in matches against other players.
Not affiliated with Roblox Corporation. Install with `install.bat`, run with `run.bat`. Tests: `pytest`.
